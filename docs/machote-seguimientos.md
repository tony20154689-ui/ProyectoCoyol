# Machote de Seguimientos — Plantilla Base para Proyectos

Este documento es la **plantilla oficial** de seguimientos que se usa como base para cada nuevo proyecto (Coyol, SARO, y futuros). Cada frente agrupa tareas por área con responsable y prioridad sugeridos.

Al arrancar un proyecto nuevo, se copia esta lista y se ajusta según necesidad. En SARO se aplicó vacía (mismo esqueleto, estado inicial en Pendiente, avance 0).

Fuente de verdad en código: `src/Tracker.jsx` → `initialData()` para la plantilla completa (con estados de Coyol) e `initialDataBlank()` para la versión en blanco.

## Cómo usar este machote para un nuevo proyecto

1. En `src/Tracker.jsx` la función `initialDataBlank()` ya devuelve esta misma lista con estados en Pendiente y avance 0.
2. Al agregar un nuevo proyecto en `src/ProjectSelector.jsx`, el `docId` nuevo será seedado automáticamente con esta plantilla vacía la primera vez que se abre.
3. Los responsables por defecto se pueden dejar como están y luego editar por proyecto.
